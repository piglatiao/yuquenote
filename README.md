# Flowing Light Notes ✨

Flowing Light Notes 是一个本地优先的知识库与文件协作系统，前端基于 React + Vite，后端基于 Node.js，数据持久化使用 SQLite，上传文件保存在磁盘目录中。

## ✨ 系统功能介绍

### 👤 账号与个人空间

- 支持注册、登录、切换账号。
- 支持编辑个人资料，包括昵称、邮箱、密码和头像。
- 每个账号都有独立的个人空间，个人笔记和个人文件彼此隔离。

### 📝 笔记与知识库

- 支持树状知识库结构，可创建文件夹、子文件夹和笔记。
- 支持新建笔记、重命名、删除、收藏和快速检索。
- 支持富文本编辑，适合记录文档、方案、说明和日常笔记。
- 支持评论、待办事项和自动保存，减少内容丢失风险。
- 左侧知识库支持超长内容滚动，避免目录过长时无法查看。

### 📁 文件管理

- 支持按文件夹整理上传内容。
- 支持图片、视频等资源的预览与管理。
- 支持文件收藏、移动、删除、分享和空间内归档。
- 文件索引保存在数据库中，实际文件保存在磁盘目录，方便备份和迁移。

### 👥 团队空间协作

- 支持创建团队空间、加入团队空间、邀请成员、移除成员。
- 支持空间设置、成员限制、头像设置和空间管理。
- 支持在个人空间与团队空间之间切换。
- 支持团队内共享知识库、文件和协作内容。

### 🔗 分享与转存

- 支持文档分享与文件分享。
- 支持生成分享链接，并可在系统中查看分享记录。
- 支持把分享内容转存到自己的空间中继续使用。
- 支持空间级资源共享，便于团队内流转资料。

### 🗑️ 回收站与持久化

- 支持空间解散后的回收站保留机制。
- 支持已解散空间的数据回看与恢复操作。
- 所有核心业务数据保存在 `data/app.db`。
- 上传文件默认存放在 `data/files/` 下，便于长期持久化保存。

### 🎵 背景音乐能力

- 支持 QQ 音乐和网易云音乐音源配置。
- 支持登录音源、管理播放队列、控制播放状态。
- 支持紧凑音乐卡片与完整播放器界面。
- 发布版已关闭调试快照落盘，不再生成调试日志文件。

## 🚀 发布脚本

当前发布只保留根目录 4 个脚本：

- `deploy-windows.bat`
- `start-windows.bat`
- `deploy-linux.sh`
- `start-linux.sh`

详细说明请查看 [RELEASE.md](RELEASE.md)。

## 🔐 账号说明

- 发布版不再自动写入默认演示账号。
- 首次启动后，请直接在登录页注册新账号。

## 💻 本地开发

安装依赖：

```bash
pnpm install
```

启动开发环境：

```bash
pnpm dev
```

## 📦 数据目录

请保留以下路径：

- `data/app.db`
- `data/files/`
